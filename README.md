# 桝Happy

集水桝の一括生成ツール群です。

## 概要
- `00_Masu_Tougou.py` を起点に、条件入力から DXF/数量計算書までをまとめて生成できます。
- 生成結果は `output_Masu_*` 配下に保存されます。

## 使い方（Linux / Lubuntu）
1. Python 3.10 以上を用意します。
2. ターミナルで `./Masu_Tougou_起動.sh` を実行します（初回のみ `chmod +x Masu_Tougou_起動.sh` が必要です）。
   - 初回のみ、仮想環境(`.venv`)の作成と依存パッケージ(`ezdxf`)のインストールを自動で行います。
   - 既存の `.venv` が壊れている場合（NTFS等のドライブでシンボリックリンクが無効になっている場合など）は自動で作り直します。
   - 2回目以降はそのまま `00_Masu_Tougou.py` が起動します。
3. 対話形式で条件を入力し、出力フォルダを確認します。

## 使い方（Windows）
1. Python 3.10 以上を用意します。
2. `Masu_Tougou_起動.bat` をダブルクリックします。
   - 初回のみ、仮想環境(`.venv`)の作成と依存パッケージ(`ezdxf`)のインストールを自動で行います。
   - 2回目以降はそのまま `00_Masu_Tougou.py` が起動します。
3. 対話形式で条件を入力し、出力フォルダを確認します。

## 依存関係
- DXF生成に `ezdxf` を使用します（`requirements.txt` 参照）。それ以外は標準ライブラリのみです。

## 注意
- 実行には `tools/` 配下の補助スクリプトが必要です。
